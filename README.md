# Apollo 11 — The Journey

A Vite + Three.js educational Apollo 11 story game.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Vercel settings:
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

## Important GitHub upload note

Keep `index.html`, `main.js`, `style.css`, `package.json`, and `vercel.json` together in the repository root. Do not upload only `index.html`; the JavaScript entry file and stylesheet are required.

This is an independent educational simulation, not an official NASA product or NASA-certified training.

## Flight controls

In the Saturn V launch chapter, click **IGNITION / LIFTOFF**, adjust the throttle slider (or use **W/S**), and steer with **↑/↓** for pitch and **←/→** for yaw. Confirm the stage-separation milestones, then select **TRANS-LUNAR INJECTION** when Earth parking orbit is reached. The flight model is a simplified educational game mechanic, not a NASA flight simulator or physically validated trajectory model.

## Mission Operations realism upgrade

The in-game Mission Systems panel adds:
- illustrative environmental telemetry for oxygen, electrical reserve, coolant and communications lock;
- a sequentially trackable mission procedure checklist;
- crew responsibilities for Armstrong, Aldrin and Collins;
- flight director notes that change during powered flight and Earth orbit.

These are educational gameplay abstractions, not recovered Apollo telemetry, operational flight rules, or NASA-certified training. The checklist is a learning aid and does not claim to reproduce every Apollo 11 procedure.


## Story and training flow

1. **Earth / apartment** — explore a fictionalized childhood setting and learn about Neil Armstrong's early interest in aviation.
2. **NASA-era center** — discover Armstrong's Navy, NACA test-pilot, Gemini 8, and astronaut-selection background.
3. **Astronaut training** — complete interactive checklist, geology, spacecraft orientation, and teamwork learning stations.
4. **Launch Complex 39A** — control throttle, pitch, and yaw during a simplified Saturn V ascent; confirm stage separation and TLI.
5. **Moon** — explore Apollo 11's Sea of Tranquility landing, EVA, samples, and Eagle ascent/rendezvous.
6. **Earth return** — visit splashdown, USS Hornet recovery, and quarantine.

The story is based on the historical Apollo 11 mission and Neil Armstrong's documented career, but the player is an educational participant—not Neil Armstrong himself. Some scenes combine real locations and story-friendly fictional apartment details.

## Important realism note

This project is a **3D educational game**, not a NASA simulator or astronaut qualification tool. Flight controls are intentionally simplified for learning and play; the game does not reproduce Apollo guidance equations, real vehicle telemetry, or operational checklists. NASA's real astronaut training is much longer and more specialized than the in-game activities.

## Junior Astronaut Mission Trainer connection

The Mission Systems panel and training stations introduce crew communication, procedures, life-support indicators, power, coolant, and mission trade-offs. These are illustrative game values, not live NASA data. To keep the game suitable for ages 7–12, explanations use plain language and short interactive choices.
